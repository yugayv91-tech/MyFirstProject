JDBC User Management

Учебный проект по работе с базой данных MySQL с использованием JDBC и Maven.

Технологии

Java 17

Maven

JDBC

MySQL

JUnit 4

Функциональность

Реализованы следующие операции:

Создание таблицы пользователей.

Удаление таблицы пользователей.

Добавление пользователя.

Удаление пользователя по ID.

Получение списка всех пользователей.

Очистка таблицы.

Структура проекта

model — класс User.

dao — работа с базой данных.

service — бизнес-логика приложения.

util — настройка подключения к MySQL.

Main — запуск приложения.

Настройка базы данных

Создайте базу данных MySQL:

CREATE DATABASE task_jdbc;

Настройте переменные среды Windows:

DB_USER — имя пользователя MySQL.

DB_PASSWORD — пароль MySQL.

Запуск и тестирование

Откройте проект в IntelliJ IDEA и запустите класс UserServiceTest для проверки работы приложения.

Все 6 JUnit-тестов успешно пройдены.
