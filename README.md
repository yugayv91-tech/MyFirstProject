# User Management — JDBC и Hibernate

Учебный Java-проект для работы с базой данных MySQL. Реализованы две версии доступа к базе данных: JDBC и Hibernate.

## Технологии

- Java 17
- Maven
- JDBC
- Hibernate ORM 5.6.3.Final
- MySQL
- JUnit 4

## Архитектура проекта

- `model` — модель пользователя `User`.
- `dao` — интерфейс `UserDao` и реализации для JDBC и Hibernate.
- `service` — сервисный слой приложения.
- `util` — настройка JDBC-подключения и конфигурация Hibernate.
- `Main` — запуск и демонстрация CRUD-операций.

## Реализованная функциональность

- Создание таблицы пользователей.
- Удаление таблицы пользователей.
- Добавление пользователя.
- Получение пользователя по ID.
- Получение списка всех пользователей.
- Обновление данных пользователя.
- Удаление пользователя по ID.
- Очистка таблицы пользователей.

Основная реализация сервисного слоя использует Hibernate DAO. JDBC-реализация сохранена в проекте.

## Настройка базы данных

Создайте базу данных MySQL:

```sql
CREATE DATABASE task_jdbc;
```

Настройте переменные среды Windows:

- `DB_USER` — имя пользователя MySQL.
- `DB_PASSWORD` — пароль MySQL.

Учётные данные не хранятся непосредственно в исходном коде.

## Запуск проекта

1. Откройте проект в IntelliJ IDEA.
2. Убедитесь, что MySQL Server запущен.
3. Проверьте настройки переменных среды `DB_USER` и `DB_PASSWORD`.
4. Обновите зависимости Maven.
5. Запустите класс `Main` для демонстрации CRUD-операций через Hibernate.

## Тестирование

Для проверки работы приложения запустите `UserServiceTest`.

Все 6 предоставленных JUnit-тестов успешно пройдены.

## Сборка проекта

Для сборки проекта используйте Maven:

```bash
mvn clean test
```
